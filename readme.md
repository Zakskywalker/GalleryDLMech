# Gallery-DL Downloader

## Features

- GUI Mode
- CLI Mode
- URL File Support
- Browser Cookies
- External App Mode
- Logging

## Usage

python downloader.py

python downloader.py URL

python downloader.py --url-file urls.txt

python downloader.py --externalapp --url-file jobs.txt
